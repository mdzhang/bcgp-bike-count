# Bike Counts

## Instructions

- counts are divided into 15m sessions
- cyclists are
  - riding on-street
  - riding on sidewalk
  - riding on-street the wrong way
- note perceived gender
  - M (male)
  - F (female)
  - X (unknown)
- note direction
  - turning cyclists count for direction they came from
- note helmet usage by adding ^ above letter
- note bike share (Indego) usage by circling letter

### Tips

- don't count devices w/o pedals
